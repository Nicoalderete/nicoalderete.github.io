From CSV to analysis-ready data.

Exploratory analysis and a reproducible pipeline with validation, SQLite and load auditing.

PythonPandasSQLiteData Quality

Question and scope

Explore an airport sample

Analyse passenger movements by airport and country using the Kaggle Top 100 Airports sample. The CSV does not state a year, so its figures are not presented as current traffic.

My contribution

Python data preparation, exploratory analysis and visualisation. A learning extension adds validation, SQLite loading and auditing to practise reproducible processes.

A load that validates before publishing

Contract and quality

Field normalisation and checks for required values, types, codes and duplicates before loading. Invalid input must preserve the previous database.

Traceability and querying

SQLite organises tables and country-level analytical views. Auditing records the source hash and totals to identify the file used in each load.

View pipeline and tests ↗Read documented case ↗

Interpretation and limitations

What it supports

Comparing airports, country distribution and concentration within the sample. Geographic visualisations complement rankings.

What it does not represent

Passenger movements are not unique travellers. The sample does not represent all global traffic or support time-trend claims without a known year and comparable sources.
